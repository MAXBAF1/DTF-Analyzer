# DTF Indie Analyzer

Асинхронный монитор для темы [DTF Indie](https://dtf.ru/indie), который находит новые посты, снимает метрики по расписанию и сохраняет динамику в SQLite.

## Назначение

Монитор постоянно следит за темой [«Инди» на DTF](https://dtf.ru/indie) и фиксирует каждый новый пост сразу после появления. Для каждого поста он регулярно сохраняет, как быстро растут просмотры и другие метрики: в первую минуту, за первые 10 минут, за первый час и на более поздних точках.

Такая динамика помогает:

- понять, в какие дни и часы публикации в теме получают лучший старт;
- сравнить текущую активность ленты с историческими данными;
- решить в моменте, удачное ли сейчас время для публикации нового поста или лучше подождать.

## Возможности

- обнаружение новых постов сабсайта `64960` каждые 15 секунд через актуальный `/v2.10/timeline` endpoint;
- замеры на чекпоинтах `+15s`, `+30s`, `+45s`, `+1m`, `+5m`, `+10m`, `+30m`, `+60m`, `+3ч`, `+6ч`, `+24ч` и промежуточных точках;
- хранение просмотров, лайков, комментариев, favorites, reactions, reads, hits, timespent, online, метаданных сабсайта и истории позиции в ленте;
- расчет скорости просмотров в минуту, просмотров за последние 5 минут, ускорения и engagement rate;
- отчет по лучшим дням/часам публикации и live-индекс конкуренции.

## Установка

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Запуск монитора

```bash
python monitor.py --db dtf_indie.db --poll-interval 15 --feed-count 20 --max-track-age 10
```

При старте монитор сначала сохраняет уже видимые в ленте посты без запуска трекеров для старых публикаций. Далее он отслеживает только новые посты, которые не старше `--max-track-age` минут.

## Аналитика

```bash
python analyzer.py --db dtf_indie.db --checkpoint 60
```

`recent_competition` смотрит последние посты с замером `+10m` и возвращает рекомендацию: публиковать сейчас, публиковать осторожно или подождать.

## Ежедневные отчеты и графики

```bash
python reports.py --db dtf_indie.db --output-dir reports --checkpoint 60
```

Команда создает HTML-отчет, PNG-графики и SVG-версии графиков в каталоге `reports/`: heatmap `день × час`, среднюю кривую роста просмотров по минутам и топ-10 самых быстрых стартов текущего месяца. Отчет помогает найти день и время, когда у читающих максимальная активность, а значит посты быстрее набирают просмотры.

Для автоматического ежедневного запуска можно добавить cron-задачу, например на 23:55 UTC:

```cron
55 23 * * * cd /path/to/DTF-Analyzer && .venv/bin/python reports.py --db dtf_indie.db --output-dir reports
```
